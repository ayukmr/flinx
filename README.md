# flinx

<img src="https://static.ayukmr.com/repos/flinx/3.png" height="400">

nRF52833-based low-profile 40% keyboard.

The board uses Kailh Choc V2 switches, and purposely doesn't include any stabilizers.
The PCB fits directly inside the case and is mounted with four screws.
A USB-C port on the side is used for charging, and a switch turns the board on/off.
Once turned on, the keyboard pairs over Bluetooth to send keystrokes.

This is intended as a small board mostly for travel, and as a low-profile version of the Monokei Neko.
